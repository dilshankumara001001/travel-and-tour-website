⚡ Real-Time Status Engine

🧮 SQL Calculation

CASE WHEN CURDATE() BETWEEN booking_date
     AND DATE_ADD(booking_date, INTERVAL (days-1) DAY)
  THEN 'Ongoing'
WHEN CURDATE() > DATE_ADD(...)
  THEN 'Completed'
ELSE 'Upcoming' END
🟢 Ongoing
Today is inside range
🔴 Completed
Today is after end
🔵 Upcoming
Today is before start
